Install features, a lighter Notifi

Read this first

  1. A feature is either installed or not. Installed means it is on and has its settings page. One state, no separate switch.
  2. Uninstalling keeps your choices for it, so installing it again puts them back.
  3. Today Notifi opens about 21 web views at launch (about 1.7 GB in total) whether or not the features behind them are on. Phase 2 stops that.
  4. Phase 1 is the new settings and the install flow. Phase 2 is the lightness. Both ship in this branch, one after the other.

1. What changes in settings

  • Sidebar: Installed and Install features at the top, then the core pages (General, Tray and panel, Shortcuts, Permissions, About), then only the features you have installed, grouped by kind.
  • Install features page: every feature, with search, a category filter, list or grid view, and an Install button on each.
  • Installed page: the features you have, in list or grid view. Click one to open its settings; Uninstall sits on each.
  • Breadcrumbs replace the page title: Installed > Island, Install features > Radial menu, Settings > General. Each part is a link.
  • Feature page header: the on/off switch becomes Install or Uninstall.

2. First run

  • The first launch opens a chooser: Just the basics, Recommended, or Everything, then tick or untick anything. Install selected, or Skip.
  • People who already have features on are treated as set up, so they never see it.

3. Checklist

Phase 1: settings and install flow

  • Rust: setup flag, recommended features, existing-user migration, tests
  • Breadcrumb bar
  • Installed page with list and grid view
  • Install features page with search and categories
  • Install and Uninstall on feature pages, search shows uninstalled features
  • Sidebar shows core pages and installed features only
  • First-run chooser
  • Check in the running app, commit

Phase 2: actually light

  • Measure memory and web view count before (21 web views, 26 processes, about 1.76 GB)
  • Build each feature's windows only when it is installed, and close them when it is removed (src-tauri/src/lifecycle.rs)
  • Measure after with the 15 features and Island installed: 14 web views, 19 processes, about 1.28 GB. Not measured: a clean install and everything installed

4. Risks

  • Some features share windows or a background thread; those need care so uninstalling one does not break another.
  • A feature's shortcut stops working when it is uninstalled. That is the point, but the shortcuts page should say why.
