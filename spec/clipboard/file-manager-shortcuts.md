# File manager shortcuts (adapted)

Only one Mac idea is kept: paste a copied image as a PNG file in Explorer, Dolphin and Nautilus.

## User-visible behaviour
- With an image on the clipboard, a shortcut in a file manager saves it as a PNG in the current folder.
- Name is timestamped.

## Settings
- Enable
- Shortcut

## Default shortcuts
Ctrl+Alt+V (Notifi design, not from source docs). (Cmd maps to Ctrl, Option to Alt, Control to Ctrl/Win as fits.)

## Edge cases
- Cut/paste and F2 rename already exist natively.

## Permissions
Windows: UI Automation to find the folder. Linux: D-Bus file manager interface.

## Platform notes
- Windows: Explorer.
- X11: Active file manager.
- KDE Wayland: Dolphin.
- GNOME Wayland: Nautilus.
