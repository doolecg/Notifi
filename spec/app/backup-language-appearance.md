# Settings backup, language, appearance and reset

## User-visible behaviour
- **Backup:** export the whole setup to a file and import it on another computer. Machine-specific paths (capture folders, music app path) and personal content (clipboard, scratchpad, shelf) are not exported.
- **Language:** more than a dozen languages, switched live, with a first-run chooser. Translations are community contributions.
- **Appearance:** follow the OS, or stay light or dark on its own; translucent materials (the Mac "Liquid Glass") become an acrylic/blur toggle where the OS offers one; reduced motion follows the OS and has its own switch.
- **Panel layout:** reorder or hide panel sections, compact layout, section navigation mode.
- **Search** in settings, sidebar hide/show shortcut.
- **Advanced:** clear all permissions and grants, and uninstall Notifi completely (login item, rules, preferences), each with a confirmation.
- **Support:** donation link and community link in the About page.

## Settings (defaults)
- Language: system; theme: system; reduced motion: system

## Default shortcuts
Ctrl+Win+S toggles the settings sidebar (Notifi design).

## Edge cases
- Backups restore local exceptions without bringing foreign paths.

## Permissions
None.

## Platform notes
- Windows: acrylic via the window backdrop. Linux: blur where the compositor supports it.
- Status: Windows PORT, Linux PORT (translucency PARTIAL).
