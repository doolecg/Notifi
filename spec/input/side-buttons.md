# Side buttons (adapted)

Back and Forward side buttons already work on Windows and Linux in most apps, so Notifi folds them into button remapping.

## User-visible behaviour
- Default pass-through.
- Can be remapped from the button remap table for apps that ignore them.

## Settings
- Remap table (shared)

## Default shortcuts
None. (Cmd maps to Ctrl, Option to Alt, Control to Ctrl/Win as fits.)

## Edge cases
- No separate feature page; this is a section inside Mouse buttons.

## Permissions
As mouse buttons.

## Platform notes
- Windows: Mouse hook.
- X11: evdev.
- KDE Wayland: Same.
- GNOME Wayland: Same.
